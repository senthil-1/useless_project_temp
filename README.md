### Project Description
The Ministry of Uesless Affairs is a Government portal powered by AI which aims to turn pointless activities,complaints and achievements into entertaining experiance.people  are able to report incidents,ask for custom AI-produced certificates,track their applications,see their profile receive notices from various  departments that are generated dynamically

### The Problem (that doesn't exist)
citizens are suffering from a severe lack of offical recognition for their completely unnecessary achievements,pointless complaints,excessive waiting,and everyday acts of uselessness. There is currently no government department dedicated to taking these matters seriously-so we created one .

### The Solution (that nobody asked for)
We built the Ministry of Uesless Affairs-a fully functional Ai-powered government portal that takes citizens most unnecessary problems seriously.Citizens can report pointless incidents,request ridiculous custom certificates,track their applications,earn Useless points,and receive AI-generated notices from various Minidtry deperatments.Because apparently,even uselessness deserves proper documentation.

## Technical Details
### Technologies/Components Used
For Software:
- Languages used : Typescript
- Frameworks used : Next.js 15 (App Router), React
- Libraries used : Firebase (Auth + Firestore), Google Gemini AI (@google/genai), React Hook Form, Zod, Lucide React, Sharp, opentype.js
- Tools used : Tailwind CSS, Cormorant Garamond & Libre Baskerville fonts, VS Code, Git



### Implementation
For Software:
# Installation
git clone <repo-url>
cd useless-3.0-1
npm install

create a .env.local file in the project root
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.5-flash-lite

# Run
npm run dev
Open http://localhost:3000
